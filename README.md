# OOPS Banner App

A Java console-based application that demonstrates multiple approaches to printing the **"OOPS"** banner using Object-Oriented Programming concepts and different Java programming techniques. The project progressively evolves through multiple use cases, showcasing various implementation strategies while reinforcing core Java concepts.

---

## About the Project

The OOPS Banner App is a learning-oriented Java project that demonstrates how the same problem can be solved using different programming techniques. Starting from a simple program that prints "OOPS" on the console, the project gradually evolves into a modular banner-printing application by introducing new Java concepts in each use case.

Rather than creating separate programs, the project continuously enhances a single `OOPSBannerApp.java` file. Every use case builds upon the previous implementation by applying improved design approaches such as `String.join()`, arrays, loops, helper methods, Object-Oriented Programming principles, and the Java Collections Framework.

The project also follows a Git feature branch workflow, where each use case is implemented in an individual feature branch and then merged into the development branch. This demonstrates both Java programming concepts and collaborative version control practices.

## Git Workflow

The project follows a feature branch workflow.

- `main` – Initial project setup
- `dev` – Development branch
- `feature/UC1-PrintOOPS`
- `feature/UC2-PrintOOPS`
- `feature/UC3-PrintOOPS`
- `feature/UC4-PrintOOPS`
- `feature/UC5-PrintOOPS`
- `feature/UC6-PrintOOPS`
- `feature/UC7-PrintOOPS`
- `feature/UC8-PrintOOPS`

Each feature branch introduces a new implementation approach by enhancing the same `OOPSBannerApp.java` file. After successful implementation and testing, the feature branch is merged into the `dev` branch, allowing the project to evolve incrementally while maintaining a clean Git history.
